<!-- feature-intro -->
Super Table has reached end-of-life for Craft 5, but existing sites still have a supported upgrade path. Its Craft 5 release converts Super Table fields and content to native Matrix so projects can move forward without rebuilding those structures by hand.
<!-- feature-intro-end -->

<!-- feature-section -->
## A clear Craft 5 path

Upgrade the project with its existing Super Table fields in place, then let the migration convert their configuration and content to Craft 5 Matrix. The result uses Craft’s native field type rather than keeping a retired content model alive indefinitely.

<!-- feature-section-end -->

<!-- feature-grid -->
- :icon[layout] **Layout preservation** Preserve table, row and static presentation intent where Craft’s Matrix settings allow it.
- :icon[binary-tree] **Nested content** Handle Super Table fields nested within Matrix and supported [Vizy](/craft-plugins/vizy) content.
- :icon[terminal-2] **Migration command** Run the Craft 5 conversion on demand when an upgrade needs explicit control.
<!-- feature-grid-end -->

<!-- feature-section -->
## Retired, not abandoned

Super Table is no longer offered as an active field-building choice on Craft 5. The release exists to make the transition predictable, including continued fixes for migration edge cases discovered by upgrading projects.
<!-- feature-section-end -->
