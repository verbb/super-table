Super Table has reached end-of-life for Craft 5, but existing sites still have a supported upgrade path. Its Craft 5 release converts Super Table fields and content to native Matrix so projects can move forward without rebuilding those structures by hand.

## Features

- **Field conversion:** Convert existing Super Table field definitions into native Matrix fields.
- **Content migration:** Carry blocks and their field values into the new Matrix structure.
- **Layout preservation:** Preserve table, row and static presentation intent where Craft’s Matrix settings allow it.
- **Nested content:** Handle Super Table fields nested within Matrix and supported Vizy content.
- **Migration command:** Run the Craft 5 conversion on demand when an upgrade needs explicit control.
- **Native result:** Finish with Matrix fields that can continue with the rest of the Craft project.
